## CADRAGE

Goal:
Permettre de **replier complètement la sidebar gauche** via un **chevron sur sa frontière** (au niveau de la poignée de resize existante) pour libérer de la largeur board, avec **état mémorisé** entre rechargements. Ré-ouverture par le même chevron → la sidebar retrouve sa largeur précédente.

Persona impact:
- **Arnaud / utilisateur Atelier** — gagne de la largeur utile (surtout depuis le pipeline board 6 colonnes de WI-013) quand il n'a pas besoin de la navigation. Confort, zéro impact métier.
- **Claude** — ajout localisé : 1 bouton chevron + 1 classe CSS de collapse + persistance localStorage. Se greffe sur le resize existant sans le casser.
- **Utilisateur final** — aucun ; app mono-utilisateur.

Context:
- **Largeur pilotée par `--sidebar-width`** (`:root`, défaut `240px` — [index.html:13](../index.html#L13)) ; grille `.app { grid-template-columns: var(--sidebar-width) 1fr }` ([index.html:164](../index.html#L164)).
- **Resize par drag existant** : poignée `.sidebar-resizer` fixed à `left: var(--sidebar-width)` ([index.html:172-189](../index.html#L172), `#sidebarResizer` [index.html:2037](../index.html#L2037)) ; `applySidebarWidth(px)` clamp `[180, 480]` ([index.html:5875](../index.html#L5875)) ; persistance `localStorage['atelier-sidebar-width']` au mouseup ([index.html:5871](../index.html#L5871), [index.html:5897](../index.html#L5897)) ; restauré au boot par `loadSidebarWidth()` ([index.html:5925](../index.html#L5925)).
- **Sidebar** : `<aside class="sidebar">` grid-area sidebar ([index.html:1992](../index.html#L1992), [index.html:262](../index.html#L262)).
- **Responsive** : `@media` ([index.html:1931](../index.html#L1931)) bascule déjà `.app` en colonne unique (`grid-template-areas: "topbar" "main"`) → à ne pas casser.
- **Zéro donnée / Gist** : la largeur (et bientôt l'état replié) sont des préférences UI localStorage, hors état applicatif persisté dans le Gist.

Constraints:
- **Ne pas casser le resize par drag** ni la persistance de largeur existante.
- **Collapse via classe** (ex. `.app.sidebar-collapsed { grid-template-columns: 0 1fr }`) plutôt que d'écraser `--sidebar-width` → la largeur resize est **préservée** et restaurée automatiquement au déploiement.
- **Chevron toujours accessible** même sidebar repliée (sinon impossible de ré-ouvrir).
- **Poignée de resize masquée/désactivée** quand replié (pas de resize d'une sidebar à 0).
- **Persistance séparée** : nouvelle clé `localStorage['atelier-sidebar-collapsed']` — jamais dans le Gist.
- **Cohabiter avec le breakpoint responsive** ([index.html:1931](../index.html#L1931)).
- **Pas de refonte design system** ni des tokens CSS.

Out of scope:
- **Rail réduit** (sidebar étroite avec icônes seules) — on fait un collapse **total**, pas un mini-rail.
- Animation de transition élaborée (une transition CSS simple suffit).
- Collapse de panneaux internes à la sidebar (projets/sprints/epics) — hors sujet.

Open questions (posées à Arnaud — la plupart pré-validées au CADRAGE de WI-013 « sidebar ok ») :

1. **Collapse total** (largeur 0, sidebar masquée) — confirmé WI-013. → reconfirmer OK.

4. **Raccourci clavier** (type `Ctrl/Cmd+B` comme VS Code) pour toggler ? **Reco Claude : hors-scope** (garde le WI FAST_TRACK ; ajout trivial dans un WI futur si besoin).

## 🎛️ Sidebar repliable (ATE-35)

Tu peux désormais **replier complètement la barre latérale gauche** d'un clic sur le **chevron** posé sur sa frontière, pour libérer de la largeur (pratique avec le pipeline board 6 colonnes de la v0.22.0). Un second clic la redéploie à sa largeur précédente.

## ✨ Ce qui change pour toi

- **Chevron sur la frontière** de la sidebar : `‹` pour replier, `›` pour déplier. Il reste accessible collé au bord gauche même quand la barre est repliée.
- **Collapse total** : la sidebar disparaît (largeur 0), tout l'espace passe au contenu.
- **Largeur préservée** : la largeur réglée au drag est conservée — la ré-ouverture y revient exactement.
- **Mémorisé** : l'état replié/déplié est retenu entre deux rechargements.
- **Aucun impact données** : préférence d'affichage locale (comme la largeur de resize), jamais synchronisée dans le Gist.

## 🛠️ Détails techniques

- Toggle d'une classe `.app.sidebar-collapsed` (`grid-template-columns: 0 1fr`) — le resize existant (`--sidebar-width`) reste intact, d'où la restauration de largeur ; poignée de resize masquée quand replié.
- Persistance : nouvelle clé `localStorage['atelier-sidebar-collapsed']`, restaurée au boot avant le premier render.
- Bouton chevron `#sidebarToggle` fixed sur la frontière (glyphe via `::before` selon l'état). Neutralisé sous le breakpoint `max-width:900px` (où la sidebar est déjà masquée).

## 🧪 Tests

- **5 nouveaux tests E2E** (`tests/sidebar-collapse.spec.js`) : toggle, chevron, persistance reload, resizer masqué, largeur préservée. TNR complet : **190 passed / 0 failed**.
